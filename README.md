# AI Rock-Paper-Scissors Match Manager

An interactive game framework written in Python that allows users to test their probability strategies against a computer AI player that is randomized and shows point aggregations round by round.

## 🚀 Key Features

* **Infinite Match Loop:** Uses custom while conditions to support gameplay until the user requests to close the game.

* **Randomized AI Engine:** Makes computer moves using selection distributions across multiple options.

* **Memory State Retention:** Keeps track of scoring variables that change based on the results of each round.

* **Robust Input Sanitization:** Handles lowercasing, stripping whitespace and input constraints to make sure the program never crashes because of text errors.

## 💻 How to Run Locally

1. Clone this repository.

2. Open a terminal inside the folder. Run:

```bash

python game.py

```
